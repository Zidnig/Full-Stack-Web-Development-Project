# Simple Task App
TypeScript + React + Next.js + Tailwind CSS

Run: npm install then npm run dev, open http://localhost:3000

| Requirement | File |
|---|---|
| TypeScript | all `.ts` / `.tsx` files (typed props, `useState<string[]>`) |
| React component | `components/TaskList.tsx` |
| React hooks | `app/page.tsx` (`useState`, `useEffect`) |
| Next.js routing | `app/page.tsx` (/) and `app/about/page.tsx` (/about) |
| Next.js API route | `app/api/tasks/route.ts` (GET, POST) |
| Tailwind CSS | `className` styling throughout |
